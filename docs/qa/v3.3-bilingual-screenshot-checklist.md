# MERIDIAN v3.3.0 中英文截图人工检查清单

## 使用方法

1. 依次检查 `tests/visual_baselines/en/` 与 `tests/visual_baselines/zh_hans/` 中同名图片。
2. 每组先看英文，再看中文，确认布局结构一致且语言切换没有改变控件位置。
3. 有意修改界面后，如需重建图片，运行：`python tools/update_visual_baselines.py --yes`。
4. 只有确认全部 24 张图片的变化都符合预期后，才提交新的基准图。

## 每张图片都要检查

- [ ] 图片尺寸为 1280×720，没有黑屏、空白或截断。
- [ ] 中文全部使用项目内置像素中文字体，没有宋体、微软雅黑等系统字体回退。
- [ ] 中文字号、基线和英文版本协调，没有异常偏大、偏小或上下漂移。
- [ ] 标题、按钮、标签、数值均在边框内，没有重叠、贴边或越界。
- [ ] 相邻文本之间留有清晰间距，长中文没有压住图标和按钮。
- [ ] 像素线条保持整数缩放，没有模糊、半像素边缘或颜色渗出。
- [ ] 英文原版与中文版表达一致，没有漏译、错译或残留英文。
- [ ] 固定时间为 12:34，电量为 88%，画面没有随机变化。

## 12 个关键页面

### 1. desktop_page_1

- [ ] 六个桌面图标、标题和状态栏对齐。
- [ ] 中文游戏名称没有压住图标边框。
- [ ] 音量入口、翻页按钮和退出提示完整可见。

### 2. desktop_page_2

- [ ] 第二页图标布局与第一页保持同一网格。
- [ ] Tank Duel、设置、档案等中英文标题居中且不重叠。

### 3. system_settings

- [ ] 设置标题、左右栏目和底部按钮对齐。
- [ ] 三路音量上线后，主音量、音乐、音效标签与数值分别对应。
- [ ] 中英文长标签不会侵入滑块、选择框或相邻栏目。

### 4. profile_statistics

- [ ] 全局信息、各游戏统计行和返回按钮边界清晰。
- [ ] 数字列纵向对齐，中文标题不会挤压数值。
- [ ] 后续完成度卡片上线后，八世界卡片尺寸和间距一致。

### 5. achievement_wall

- [ ] 成就格子数量、分页和选中状态正确。
- [ ] 已解锁、锁定和进度状态能明显区分。
- [ ] 中文成就标题或提示没有溢出底部栏。

### 6. lore_list

- [ ] 分类标签、条目列表和底部提示均在安全区域内。
- [ ] 锁定条目只显示允许的信息，不泄露正文。
- [ ] 中文分类名称和条目标题不重叠。

### 7. tank_menu

- [ ] 标题、红蓝阵营、VS、规则摘要和三个按钮层次清楚。
- [ ] 中文“坦克对决”使用正确像素字体和字号。

### 8. tank_controls

- [ ] WASD/F 与方向键/Enter 两套操作说明清楚分组。
- [ ] 八种道具名称或图标均可辨认，没有字母占位图标。

### 9. tank_playing

- [ ] 红蓝 HUD 左右对称，蓝方文字保持右锚定。

### 10. tank_paused

- [ ] 暂停遮罩居中，背景仍能辨认但不会抢夺注意力。
- [ ] 中英文暂停标题、继续和菜单提示均完整。
- [ ] HUD 不因暂停发生位置跳动。

### 11. tank_sudden_death

- [ ] 骤死阶段提示、倒计时和比分清晰。
- [ ] 警示色不会遮挡红蓝 HUD 或地图内容。
- [ ] 中英文提示强度一致，文字没有越界。

### 12. tank_end

- [ ] 胜者、最终比分、双方命中率和道具使用数均为非默认数据。
- [ ] 红蓝统计分别左/右锚定，不发生蓝方文字移位。

- [ ] 平局、红胜、蓝胜的文案区域都预留足够宽度。
