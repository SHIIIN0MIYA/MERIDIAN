## 🌌 مقدمة

**MERIDIAN (‫子午线‬)** هو جهاز محمول من أصل مجهول. "شاشته" ليست شاشة عادية — إنها **عدسة رنين**. سبع شظايا من الواقع مختومة داخل سبع ألعاب أركيد كلاسيكية، كل منها بمثابة بوابة مستقرة إلى عالم مستقل.

هذه ليست منصة ألعاب عادية. إنها **جهاز مراقبة بين الأبعاد**.

مبني باستخدام **Python + Pygame**، هذا المشروع هو محاكي كامل لمنصة متعددة الألعاب. يجمع بين:

- 🎮 **سبع ألعاب أركيد كلاسيكية معاد إنشاؤها بالكامل**
- 📚 **نظام سردي عميق لبناء العالم**، لكل لعبة قصتها الخاصة
- 🏆 **أكثر من 50 إنجازاً** يتتبع تقدم اللاعب عبر الألعاب
- 🌍 **دعم ثنائي اللغة كامل** (الصينية المبسطة / الإنجليزية)
- 💾 **حفظ مقاوم للأعطال** مع إمكانية استئناف اللعبة من المنتصف
- 🎵 **محرك صوتي إجرائي** يولد موسيقى ومؤثرات صوتية ديناميكية
- 🛠 **لوحة مطور مدمجة** للتصحيح والاختبار

## 🌠 بناء العالم

MERIDIAN أكثر من مجرد مجموعة ألعاب — إنه يمتلك إطاراً **سردياً شاملاً**:

- **تسلسل الإقلاع**: معايرة الرنين → مسح الأبعاد → تثبيت المرساة → اتصال النواة
- **مصادقة كلمة المرور**: "NEXUS AUTHENTICATION" — التحقق من تطابق الرنين
- **بيئة سطح المكتب**: شريط الحالة يعرض معرف جهاز "MERIDIAN"
- **نظام المقدمات**: كل لعبة تعرض مقدمة من 3-5 أسطر عند الزيارة الأولى
- **أرشيف المعرفة (LORE)**: قارئ مستقل في صفحة سطح المكتب الثانية، يحتوي على:
  - 8 علامات تبويب للفئات (أصل الأداة + العوالم السبعة)
  - قصص خلفية الجهاز (الأصل / نواة الرابط / الحامل)
  - 1-2 إدخالات معرفة عميقة لكل عالم
  - إدخالات مخفية تُفتح عبر الإحصائيات أو الإنجازات
- **نص الأجواء**: صفحة قائمة كل لعبة تعرض نصاً جوياً لبناء العالم
- **ثنائي اللغة بالكامل**: جميع النصوص تدعم الصينية والإنجليزية

## ✨ الميزات

### 🎯 التجربة الأساسية

- **رسوم متحركة للإقلاع**: تسلسل بدء تشغيل كامل لعالم MERIDIAN مع شريط تقدم من أربع مراحل
- **شاشة قفل بكلمة مرور**: لوحة مفاتيح رقمية + مفتاح حذف، واجهة مصادقة بتقنية البكسل آرت
- **بيئة سطح المكتب**: تخطيط أيقونات من صفحتين، جسيمات أثر الفأرة، رسوم متحركة للساعة كل ساعة
- **قوائم داخل اللعبة**: واجهة موحدة بأسلوب الأركيد مع متابعة / لعبة جديدة / إعدادات

### 🏆 جدار الإنجازات

- شبكة شارات إنجاز 8×6
- انقر على الشارة لتوسيع بطاقة التفاصيل (رسوم متحركة سهلة التراجع)
- زر إغلاق بتقنية البكسل آرت
- إحصائيات تقدم الفتح، خلفية متدرجة، خط فاصل ذهبي
- علامات نجمة ذهبية على الشارات المفتوحة
- ما يصل إلى 3 إشعارات إنجاز مكدسة في وقت واحد

### 💾 نظام الحفظ

| الوظيفة | الوصف |
|----------|------|
| **حفظ تلقائي** | يتم حفظ حالة اللعبة تلقائياً عند الخروج |
| **استئناف** | يظهر زر "متابعة" عند إعادة دخول اللعبة |
| **مقاوم للأعطال** | كتابة ذرية + آلية نسخ احتياطي تمنع تلف الحفظ |
| **ترحيل الإصدار** | المخطط v4، يدمج بيانات الحفظ القديمة تلقائياً |
| **إحصائيات عبر الألعاب** | تتبع موحد لوقت اللعب ومعدلات الفوز وأفضل النتائج |

### ✈️ محتويات Air Raid الحصرية

- **نظام جلود المركبة**: 4 جلود قابلة للفتح (DEFAULT / CRIMSON / AZURE / GOLD)
- **نظام القصة**: مقدمة + 8 فصول من خط القصة، مترجمة بالكامل
- **أرشيف القصص**: قارئ بملء الشاشة يضم 9 إدخالات
- **16 مهمة قياسية** + Boss Rush + نمط التحدي
- **نظام ترقية الأسلحة**: Cannon / Spread / Laser / Missile

### 🎨 المؤثرات البصرية

- لوحة ألوان موحدة (الفئة `C` تدير مركزياً أكثر من 45 لوناً لـ Air Raid)
- نظام جسيمات سطح المكتب (أثر الفأرة / شرارات التمرير / انفجار الساعة)
- رسوم متحركة انتقالية للخروج خاصة بكل لعبة
- انتقال Air Raid ثلاثي الطبقات (غلاف نجمي + ستار رصاص + حلقات رادار متحدة المركز)
- حدود زخرفية لبطاقات تفاصيل الإنجاز (زوايا بأسلوب Cuphead)

### 🌍 الترجمة

- تبديل ديناميكي للغة في وقت التشغيل
- خط Fusion Pixel Font — النسخة النسبية للصينية المبسطة
- `localization.py` إدارة مركزية للترجمة مع تسجيل دفعي
- التغطية: تسميات واجهة المستخدم، قوائم الألعاب، أوصاف الإنجازات، نصوص القصة، إدخالات Lore

### 🛠 أدوات المطور

- **لوحة المطور F10**: تمييز عند تمرير الفأرة + نقر للتفعيل
- الوظائف: فتح جميع المستويات، جميع الجلود، تشغيل المؤثرات الساعية، مسح الحفظ، إلخ
- تأثيرات تقتصر على الجلسة فقط، لا تؤثر على البيانات الدائمة

## 🚀 بداية سريعة

### المتطلبات

| الاعتمادية | الإصدار |
|------------|---------|
| Python | **3.10+** |
| pygame | **2.0+** (<3.0) |
| نظام التشغيل | Windows / macOS / Linux |

### التثبيت والتشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/CrescentXiong-1/MERIDIAN.git
cd MERIDIAN

# 2. تثبيت الاعتماديات
pip install -r requirements.txt

# 3. التشغيل
python MERIDIAN.py
```

> 💡 **ملاحظة**: الاعتمادية الوحيدة هي `pygame`. لا توجد مكتبات خارجية أخرى مطلوبة.

### المشاركة

قم بضغط مجلد `MERIDIAN` بالكامل وأرسله. يحتاج المتلقي فقط إلى Python 3.10+ و `pip install pygame`.

## 🏗 الهندسة المعمارية

يستخدم MERIDIAN **نمط تركيب Mixin**:

```
Game(
    ShellMixin,         # الإقلاع / سطح المكتب / كلمة المرور / الانتقالات
    GomokuMixin,        # غوموكو
    MinesMixin,         # كاسحة الألغام
    Game2048Mixin,      # 2048
    BreakoutMixin,      # بريك آوت
    SnakeMixin,         # الثعبان
    TetrisMixin,        # تتريس
    ArcadeHubMixin,     # أنظمة أركيد مشتركة
    AirRaidMixin,       # غارة جوية
    DeveloperMixin,     # أدوات المطور
    SystemMixin,        # الإعدادات / الإنجازات / المعرفة
)
```

### أنماط التصميم الأساسية

| النمط | التطبيق |
|-------|---------|
| **آلة الحالة** | توجيه ثلاثي الجداول: `_EVENT_DISPATCH` + `_UPDATE_DISPATCH` + `_DRAW_DISPATCH` |
| **التسجيل الديناميكي** | `_GAME_STATE_REGISTRY` يسمح بإضافة ألعاب جديدة دون تعديل `app.py` |
| **تركيب Mixin** | كل وحدة لعبة ونظام محقونة في `Game` عبر Mixins |
| **الكتابة الذرية** | الحفظ في ملف مؤقت ثم إعادة التسمية، يمنع التلف |
| **ترحيل الإصدار** | `SaveManager._deep_merge()` يملأ الحقول الجديدة تلقائياً |

### تدفق الحالات

```
BOOT → SYSTEM_READY → PASSWORD → DESKTOP
                                    ├── GOMOKU_MENU → GOMOKU_PLAYING → GOMOKU_END
                                    ├── SNAKE_MENU → SNAKE_PLAYING → SNAKE_END
```

## 🔌 واجهة برمجة التطبيقات للتوسيع

تتوفر واجهة برمجة كاملة للألعاب الجديدة:

```python
from meridian.lore import register_game_world, register_device_lore
from meridian.shell_desktop import register_desktop_icon
from meridian.app import _register_game_states
from meridian.localization import register_game_translations

# 1. تسجيل عالم لعبة (بناء العالم، المقدمة، النص الجوي، المعرفة العميقة)
register_game_world(
    "mygame",
    world_name_en="MY WORLD",
    world_name_zh="我的世界",
    world_summary_en="A world of wonder",
    world_summary_zh="奇妙的世界",
    prologue_en=["Line 1", "Line 2", "Line 3"],
    prologue_zh=["第一行", "第二行", "第三行"],
    menu_flavor_en="The crystals hum with ancient power...",
    menu_flavor_zh="水晶随着古老的力量嗡嗡作响…",
    lore_entries=[...],
    desktop_subtitle_en="MY WORLD",
    desktop_subtitle_zh="我的世界",
)

# 2. تسجيل أيقونة سطح المكتب
register_desktop_icon("MYGAME", "open_mygame", page=0, ...)

# 3. تسجيل ديناميكي لتوجيه الحالات (بدون تعديل app.py)
_register_game_states("MYGAME_MENU", "_handle_mygame_menu", [], "_draw_mygame_menu")

# 4. تسجيل الترجمات
register_game_translations("mygame", {"PLAY": "开始", "SCORE": "得分"})
```

> 📝 راجع docstrings في الكود المصدري للحصول على وثائق API الكاملة.

### تدفق المساهمة

1. **Fork** هذا المستودع
2. أنشئ فرعاً: `git checkout -b feature/ميزة-رائعة`
3. أرسل التغييرات: `git commit -m 'feat: إضافة ميزة رائعة'`
4. ادفع الفرع: `git push origin feature/ميزة-رائعة`
5. افتح **طلب سحب (Pull Request)**

### اتفاقية commits

يستخدم هذا المشروع [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` ميزة جديدة
- `fix:` إصلاح خطأ
- `docs:` وثائق
- `refactor:` إعادة هيكلة الكود
- `test:` اختبارات
- `chore:` بناء / أدوات
