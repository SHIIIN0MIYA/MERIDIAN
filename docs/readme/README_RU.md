## 🌌 Введение

**MERIDIAN** — портативное устройство неизвестного происхождения. Его «экран» — не обычный дисплей, а **Резонансная Линза**. Фрагменты множества реальностей запечатаны в игровых модулях, каждый из которых служит стабильным порталом в независимый мир.

Это не обычная игровая консоль. Это **устройство межпространственного наблюдения**.

Проект построен на **Python + Pygame** и представляет собой полноценный симулятор многопользовательской игровой платформы. Он объединяет:

- 🎮 **Восемь полностью воссозданных классических аркадных игр**
- 📚 **Глубокую систему мирового нарратива**, каждая игра с собственной историей
- 🏆 **60 достижений**, отслеживающих прогресс игрока
- 🌍 **Полная двуязычная поддержка** (упрощённый китайский / английский)
- 💾 **Краш-устойчивое сохранение** с возможностью продолжения игры
- 🎵 **Процедурный аудиодвижок** с динамической генерацией BGM и SFX
- 🛠 **Встроенная панель разработчика** для отладки и тестирования

## 🌠 Мироустройство

MERIDIAN — это больше, чем коллекция игр. Проект обладает завершённой **мета-нарративной** структурой:

- **Загрузочная последовательность**: Калибровка Резонанса → Сканирование Измерений → Стабилизация Якоря → Подключение Ядра
- **Аутентификация**: «NEXUS AUTHENTICATION» — проверка резонансного соответствия
- **Рабочий стол**: Строка состояния отображает идентификатор устройства «MERIDIAN»
- **Система прологов**: Каждая игра показывает пролог из 3-5 строк при первом посещении
- **Архив Знаний (LORE)**: Независимый читатель на второй странице рабочего стола, содержащий:
  - Вкладки, создаваемые для Артефакта и каждого зарегистрированного мира
  - Фоновые истории устройства (Происхождение / Ядро Нексуса / Носитель)
  - Обычные записи каждого мира всегда доступны для чтения
  - Условия статистики и достижений дают прогресс Lore
  - Четыре записи Резонанса открываются при 25% / 50% / 75% / 100% общего завершения
- **Атмосферный текст**: Страница меню каждой игры отображает текст мироустройства
- **Полная двуязычность**: Весь текст поддерживает китайский и английский

## ✨ Возможности

### 🎯 Основной опыт

- **Анимация загрузки**: Полная стартовая последовательность MERIDIAN с четырёхэтапной полосой прогресса
- **Экран блокировки**: Цифровая клавиатура + клавиша удаления, пиксельный интерфейс аутентификации
- **Рабочий стол**: Двухстраничная раскладка иконок, частицы следа мыши, ежечасная анимация часов
- **Внутриигровые меню**: Единый аркадный интерфейс с Продолжить / Новая Игра / Настройки

### 🏆 Стена Достижений

- Сетка значков 8×6
- Нажмите на значок для карточки с деталями (анимация ease-out-back)
- Пиксельная кнопка закрытия
- Статистика прогресса, градиентный фон, золотая разделительная линия
- Золотые звёзды на разблокированных значках
- До 3 уведомлений о достижениях одновременно

### 💾 Система Сохранения

| Функция | Описание |
|---------|----------|
| **Автосохранение** | Состояние игры сохраняется автоматически при выходе |
| **Продолжить** | Кнопка «Продолжить» появляется при повторном входе в игру |
| **Защита от сбоев** | Атомарная запись + механизм резервного копирования |
| **Миграция версий** | Schema v5, автоматическое слияние устаревших сохранений |
| **Кроссигровая статистика** | Единый учёт времени игры, побед и рекордов |

### ✈️ Эксклюзивы Air Raid

- **Система скинов корабля**: 4 разблокируемых скина (DEFAULT / CRIMSON / AZURE / GOLD)
- **Сюжетная система**: Пролог + кампания из 8 глав, полностью локализовано
- **Архив историй**: Полноэкранный читатель на 9 записей
- **16 стандартных миссий** + Boss Rush + Режим Испытания
- **Система улучшения оружия**: Cannon / Spread / Laser / Missile

### 🎨 Визуальные эффекты

- Единая цветовая палитра (класс `C`, централизованно управляющий более 45 цветами Air Raid)
- Система частиц рабочего стола (след мыши / искры при наведении / ежечасный всплеск)
- Уникальные анимации выхода для каждой игры
- Трёхслойный переход Air Raid (звёздное небо + завеса пуль + концентрические радарные кольца)
- Декоративные рамки карточек достижений (углы в стиле Cuphead)

### 🌍 Локализация

- Динамическое переключение языка во время выполнения
- Fusion Pixel Font — пропорциональный вариант упрощённого китайского
- `localization.py` — централизованное управление переводами с пакетной регистрацией
- Охват: метки UI, меню игр, описания достижений, текст историй, записи Lore

### 🛠 Инструменты разработчика

- **Панель разработчика F10**: Подсветка при наведении мыши + клик для активации
- Функции: тестовые разблокировки, принудительный результат, настройка скорости и запуск ежечасных эффектов
- Эффекты только в рамках сессии, без влияния на постоянные данные

## 🏗 Архитектура

MERIDIAN использует **композиционный паттерн Mixin**:

```
Game(
    ShellMixin,         # Загрузка / Рабочий стол / Пароль / Переходы
    GomokuMixin,        # Гомоку
    MinesMixin,         # Сапёр
    Game2048Mixin,      # 2048
    BreakoutMixin,      # Breakout
    SnakeMixin,         # Змейка
    TetrisMixin,        # Тетрис
    ArcadeHubMixin,     # Общие аркадные системы
    AirRaidMixin,       # Air Raid
    TankBattleMixin,    # Представление Tank Duel
    DeveloperMixin,     # Инструменты разработчика
    SystemMixin,        # Настройки / Достижения / Lore
)
```

### Основные паттерны проектирования

| Паттерн | Применение |
|---------|------------|
| **Конечный автомат** | Тройная таблица диспетчеризации: `_EVENT_DISPATCH` + `_UPDATE_DISPATCH` + `_DRAW_DISPATCH` |
| **Ограниченная регистрация** | Состояния, инициализаторы, иконки, Lore и переводы регистрируются до создания `Game` |
| **Композиция Mixin** | Каждый игровой и системный модуль внедряется в `Game` через Mixins |
| **Атомарная запись** | Сохранение во временный файл с последующим переименованием |
| **Миграция версий** | `SaveManager._deep_merge()` автоматически заполняет новые поля |

## 🔌 API расширений

Модуль расширения нужно явно импортировать до создания `Game()`. Автопоиска, горячей перезагрузки и стороннего протокола сохранений нет; регистрация действует только на последующие экземпляры.

```python
from meridian.lore import register_game_world, register_lore_entry
from meridian.shell_desktop import register_desktop_icon
from meridian.app import register_game_initializer, register_game_state
from meridian.localization import register_game_translations

def init_mygame(game):
    game.mygame_score = 0

def handle_event(game, event): ...
def update(game): ...
def draw(game): ...

# 1. Регистрация игрового мира
register_game_world(
    "mygame",
    world_name_en="MY WORLD",
    world_name_zh="我的世界",
    world_summary_en="A world of wonder",
    world_summary_zh="奇妙的世界",
    prologue_en=["Line 1", "Line 2", "Line 3"],
    prologue_zh=["第一行", "第二行", "第三行"],
    menu_flavor_en="The crystals hum with ancient power...",
    menu_flavor_zh="水晶随着古老的力量嗡嗡作响…",
    lore_entries=[],
    desktop_subtitle_en="MY WORLD",
    desktop_subtitle_zh="我的世界",
)

# 2. Условный прогресс Lore и инициализация расширения
register_lore_entry(
    "mygame", "mygame_mastery",
    title_en="CRYSTAL MASTERY", title_zh="水晶精通",
    content_en=["The crystal answers."], content_zh=["水晶作出了回应。"],
    unlock="stat:mygame:score:100",
)
register_game_initializer(init_mygame)

# 3. Состояние и иконка на третьей странице
register_game_state("MYGAME_MENU", handle_event, [update], draw)
register_desktop_icon(
    "MYGAME", "open_mygame", page=2,
    subtitle_en="MY WORLD", subtitle_zh="我的世界",
    target_state="MYGAME_MENU", transition_effect="fade",
)

# 4. Регистрация переводов
register_game_translations("mygame", {"MYGAME_PLAY": "开始"})
```

Обработчики могут быть именами методов `Game` или callable с аргументом `game`. Активная иконка использует ровно один вариант: `target_state` либо `on_activate(game)`. Ключи перевода принадлежат `game_id`, а конфликт требует явного `replace=True`. `_register_game_states()` сохранён только для совместимости.

> 📝 Полная документация API в docstrings исходного кода.

## 🔎 Локальная проверка релиза

Запустите проверку релиза в режиме только для чтения из корня репозитория:

```bash
python tools/check_release.py
```

Эта команда проверяет только версию, метаданные `CHANGELOG.md` и состояние Git рабочего дерева и локальных тегов версий. Она не создаёт теги, не выполняет push и ничего не собирает. Статический анализ кода можно запустить отдельно:

```bash
python -m ruff check MERIDIAN.py meridian tools
python -m compileall -q MERIDIAN.py meridian tools
```
