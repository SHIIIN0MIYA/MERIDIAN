# MERIDIAN 开发历史档案

本目录记录 MERIDIAN 从五子棋原型成长为多世界掌机平台的过程。它不是宣传文案，也不是仅列出功能的更新日志；重点是当时的问题、尝试、失败、试玩反馈、重构原因和由此形成的设计判断。

## 阅读说明

- **开发者确认**：直接来自开发者提供的 17 个阶段，作为早期时间线的事实基础。
- **代码与提交证实**：可由当前源码、设计文档、`CHANGELOG.md` 或 Git 提交核验的内容。正式 Git 标签目前只有 `v3.2.0`。
- **【推测】**：为衔接未保留提交的早期阶段所作的保守推断；它不代表被证实的历史。
- 未能可靠恢复的早期日期一律写作“未留存”，不以当前文件时间倒推。

## 文件索引

| 文件 | 用途 |
| --- | --- |
| `Development_Log.md` | 按版本叙述的完整发展史，含开发背景、测试、问题、解决与总结。 |
| `Version_History.md` | 便于浏览的版本索引与核心变化。 |
| `Bug_Log.md` | 已证实 Bug、修复方式和可复用的工程经验。 |
| `Playtest_Log.md` | 重要试玩与验证记录；早期无法核实的体验记录明确标注为【推测】。 |
| `Design_Decision_Log.md` | 从合集到掌机、从掌机到 MERIDIAN 等关键决策的来由。 |
| `Developer_Diary/` | 按开发阶段连载的第一人称开发日记（Part_01 五子棋原型至 Part_26 Lore 深化），记录每日编号记录、试错与设计判断。 |

## 版本口径

`v0.0.1` 至 `v2.x` 为本次重构用的叙事版本号，用来表达开发顺序，不声称曾经存在同名 Git 标签。`v3.0.0`、`v3.1.0`、`v3.2.0` 和正在发展的 `v3.3.0-dev` 与仓库已有变更记录对应；其中 `v3.2.0` 已有本地 Git 标签。

## 证据边界

仓库最早的完整源码快照已包含较成熟的 HAO'S GAME DECK 内容，不能单靠 Git 反推出五子棋原型的逐日过程。因此本目录宁可保留空白和【推测】，也不编造不存在的报错、日期、玩家反馈或技术突破。
